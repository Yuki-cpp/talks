The old fashionned way: Template specialization

Simple principles

  • Types ↔️ Variables
  • Classes ↔️ Functions
  • Variadics ↔️ Parameters

High cost

  • Very (very) verbose
  • Relies on recursion
  • Very (very) hard to read

Basic template specialization example

(Simplified) 2023's sort


def sort(Ts: list[Type], 
         Pred: Predicate) -> tuple:
    if len(Ts) == 0:
        return ()

    input = tuple(*Ts)
    left = split_l(input, Pred)
    right = split_r(input, Pred)

    return merge(left, right, Pred)
