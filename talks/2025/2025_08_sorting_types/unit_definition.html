What is a "unit"?

How do we define a unit in our C++ library

Sensible expression should be valid:

  • \[ 50m \times 2m \]
  • \[ 39m^{2}s^{-1} + 3m^{2}s^{-1} \]
  • \[ 39m^{2} \over 3s \]

While non-sensical ones must not:

  • \[ 5m + 5s \]
  • \[ 50m + 23 \]

Use a different C++ type for each unit

  • Little to no runtime cost
  • Strong types will allow us to enable/disable operations precisely
  • 25 SI units means up to \(25! \times 4\) operations to handle.

Variadic templates to the rescue

  • We can use a variadic template to define a unit
  • Each type in the parameter pack is a dimension and exponent
  • Only operations we use will be defined/compiled
